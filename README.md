# Mushketon Live Scoring

Система живых результатов для клубных соревнований по правилам ISSF (10 м, смешанные пары).
Поддерживаются три типа соревнования: пары, фирменное и индивидуальный финал.

- Судья вводит суммы серий на странице `/judge/`
- Зрители видят актуальный рейтинг на странице `/scoreboard/` — обновление мгновенное, без перезагрузки

## 🍴 Хочу запустить для своего клуба (fork)

Хотите свою копию — со своей базой и своим токеном судьи? Всё, что нужно —
в одном документе: **[⚙️ Настройка своей копии](docs/setup.md)**.

Коротко:

1. **Fork** этого репозитория себе в аккаунт (кнопка вверху страницы GitHub)
2. Включить **GitHub Pages** в настройках форка
3. Создать **свой** проект на [supabase.com](https://supabase.com) и выполнить `sql/supabase_setup.sql`
4. Вписать ключи своего проекта в корневой `config.js`

⚠️ После форка в `config.js` остаются ключи **оригинального** автора — пока
их не заменить на свои, форк будет писать данные в чужую базу. Подробности
и все шаги — в [docs/setup.md](docs/setup.md).
